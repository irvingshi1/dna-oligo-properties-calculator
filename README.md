# DNA Oligo Properties Calculator

The DNA oligo properties calculator is used to estimate the melting temperature (°C) and Gibbs free energy (kcal/mol) of a DNA oligo (5' → 3'). It uses the nearest-neighbor thermodynamics formula for calculating those properties using Tables 1 and 2 from John SantaLucia, Jr.'s article. Use `npm run dev` to start the program and then go to `localhost:5173`. Enter the DNA oligo, then the molar concentration (µM) to get the melting temperature and Gibbs free energy. 

## References

J. SantaLucia, A unified view of polymer, dumbbell, and oligonucleotide DNA nearest-neighbor thermodynamics, Proc. Natl. Acad. Sci. U.S.A. 95 (4) 1460-1465, https://doi.org/10.1073/pnas.95.4.1460 (1998).
